# 哈尔滨原神大学 🎮

> 原神，启动！🚀

一个搞怪的《原神》启动页面，展示原神启动动画后自动跳转到哈尔滨工程大学官网。

## 📖 项目简介

本项目是一个极简的网页应用，通过 CSS 动画展示《原神》的经典启动画面，并在动画结束后自动跳转到哈尔滨工程大学（HRBEU）官方网站。

**域名**：[www.哈尔滨原神大学.com](https://www.哈尔滨原神大学.com) ❤️

## 🎯 功能特性

- ⚡ 极简设计，单文件部署
- 🖼️ 三重启动动画（原神图标 → 加载中 → 完成）
- 🔄 4秒动画后自动跳转
- 📱 响应式设计，支持各种屏幕尺寸
- 🚀 基于 Vercel 快速部署

## 🛠️ 技术栈

- HTML5
- CSS3 (包含内嵌 Base64 图片)
- 零依赖，纯静态页面

## 📁 项目结构

```
GenshinHEU/
├── index.html    # 主页面
```

## 🚀 部署方式

### 使用 Vercel（推荐）

1. Fork 本仓库
2. 在 Vercel 中导入项目
3. 自动部署，获得 `.vercel.app` 域名
4. 可选：配置自定义域名（如：哈尔滨原神大学.com）

### 手动部署

直接将 `index.html` 和 `style.css` 上传到任何静态网站托管服务即可。

## 🎨 工作原理

1. 页面加载时显示全屏白色背景
2. 通过 CSS `@keyframes` 动画逐帧展示三张图片：
   - 0-15%: 原神启动图标
   - 15-40%: 加载中画面
   - 40-100%: 最终画面 + 跳转倒计时
3. 4秒动画结束后，JavaScript 自动跳转到目标网站

```css
animation-name: launch;
animation-duration: 4s;
animation-fill-mode: forwards;
```
